## Recommended research tests: 910B2 constraints

1. **Current stable pair and Decoding:** first measure draft-generation cost, accepted tokens per verification, verification state/materialization, per-step latency and real batch-sensitive TPS on current vLLM / vLLM-Ascend pair. Do not use H100/Hopper results as NPU speedup promises. HybridSpec requires matching hybrid recurrent+MoE target and state-reconstruction compatibility.
2. **MegaOps vs fused native:** build a small controlled dependency graph with two kernels and compare separate sequential → pipelined/tile-sync → fused native candidates. Capture event timeline, CANN graph/task/stream behavior, synchronization overhead and precise correctness; CUDA Streams/SM allocation cannot be assumed to map to Ascend hardware.
3. **EAT / KOPE / SEIS:** same model, token/search/compile/benchmark budget, same initial kernel/engine checkpoint; arm A fixed agent, B retained knowledge, C supervisor/team adaptation. Hold out shapes/models/requests, count failed candidates and full runtime regressions, measure experiment cost rather than merely successful best-of-N.
4. **Lab signal:** use SGLang native Trainium one-kernel-per-step and Muse Spark layer-megakernel as source-code study references, not proof that an Ascend monolithic megakernel is always better than staged kernels.
