## Late source supplement: Basin, distinct from Inside the Trap

**[When Cache Pressure Becomes a Trap: Metastability in Agent Serving (arXiv 2611.02543)](https://arxiv.org/html/2611.02543v1)**, submitted Nov 2, found in follow-up citation-crosswalk. **This increases the three-pass result from 896 to 897**, but is a **separate supplementary single paper**, not a retroactive eighteenth entry in the 17-row third-pass table.

- **G0:** distinct paper and authors from [Inside the Trap (2611.08902)](https://arxiv.org/abs/2611.08902); no identity duplication. G1: actual SGLang/NIXL P/D serving intervention. G2: population/cache feedback plus **Basin arrival-age priority, context reservation, admission/shedding, and decode-memory lending**. Strong baselines include HiCache, Continuum, ThunderAgent, CONCUR and Crossflow.
- **G3 actual silicon:** author reports **4×H200 1P3D / 2×H100 NVL 1P1D, Qwen3.6-35B-A3B FP8 and long-context Terminal-Bench / SWE-bench Pro sessions**. The **arrival-time priority/current-context prototype** shows H200 1P3D **1.20–1.70× Session Goodput vs Continuum, 2.35–3.59× vs HiCache** under burst scenarios, with matched tool delays and run windows. Goodput means SLO-qualified **completed sessions/h**, with rejection/shed requests as failed, not output Tokens/s. Paper explicitly states hardware prototype **does not implement future-context prediction/size-aware priority**.
- **G3 simulation separation:** prediction-driven controller across broader loads, 36-deployment criterion, and scaled 2P6D are **simulation**, with calibrated models and measured nonzero fidelity error (H100 ITL violation simulator 0.5% vs hardware 13.6% in one setting). In **decode-limited H100 1P1D** the hardware arrival-time system shows little goodput gain; do not generalize H200 result.
- **G4/G5:** original source HTML full method, explicit baselines and limitations inspected; code was not executed here. Independent Session KV state management is differentiated from *Inside the Trap*'s independent FIFO renewal-theory analysis. **KEEP_STRICT / SOURCE_G3 / NOT_REPRODUCED**.

## Seven Frontier lessons; no extra frontier categories

1. **Agent-native inference:** Penelope head-first eviction, Fairway fairness, KVGuard block safety, Robot Fleets active-episode caps; **three distinct KV concerns**: correctness, retention and admission.
2. **Real-time omni-modal:** Ripple proves explicit CPU/GPU bandwidth/Deadline contract for LLM + VLM in UMA; still **not full-duplex streaming audio/video**.
3. **Diffusion language inference:** no third-wave new KEEP; previously admitted SpecCTMC/ChainFlow remain anchors, do not invent additional new method.
4. **Interactive world-model serving:** sustained low-latency action/visual frame remains an unmet question; **robot VLA benchmark is not an interactive video world-model renderer**.
5. **Embodied VLA:** measurable RT deadline vs token Goodput, zero RTT caveat, strict stage baseline comparator.
6. **Agentic kernel engineering:** Warpline adds instrumented **memory ordering / SASS / kernel evidence**; compare its actual search budget to KDA/CAKE/ForgeKernel before extrapolating learned agent ability.
7. **Autonomous inference-engine evolution:** Controlled Engine Evaluation is a warning that an **LLM benchmark harness can optimize or exaggerate an old default** rather than engine design; no proof of agent RSI. End-to-end serving, correctness, and baseline version must be frozen.

## Research-to-experiment transfer

- **Ascend 910B2:** Flash-comm's NVLink/CUDA Graph handshakes and GC-MoE's CUDA Green Context API are *ideas to test*, not portable measured speedups. Penelope & Fairway apply at Engine Scheduler/KV lifecycle boundaries, so they may be more transferable; prove correctness and performance on pinned vLLM0.23 + vLLM-Ascend pair.
- **MPK × XY-Serve / GEMM Fusion:** megakernel ordered-completion study is **important negative evidence**, requiring Release/Acquire correctness and matched allocation/prefetch boundaries before making go/no-go claims from traces.
- **Agent-assisted kernel development:** Warpline suggests reusable **binary trace + provenance + hidden oracle + fixed budget**; do not equate better trace injection with robust autonomous optimizer learning.
- **Benchmark hygiene:** Source experiment using vLLM0.6.3/SGLang0.4.1 demonstrates baseline confounding; absolutely do not use its 64× number to rank 2026 engines.
