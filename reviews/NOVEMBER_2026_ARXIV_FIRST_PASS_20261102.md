## Research signals and practical next checks

1. **Hybrid-state residency is not conventional prefix KV reuse.** Recurrent checkpoints have a different access pattern from full KV and the right SSD/checkpoint tradeoff depends on long-lived agent branching. HiState offers hypotheses for future Ascend agentic-serving workload measurements, **not** evidence of an Ascend speedup.
2. **Define useful work at task completion.** Paired precision sweeps should report exact-task outcome quality, generated work, cache occupancy and joules-per-verified-task together, rather than labeling per-call GPU savings as deployment savings.
3. **Software provenance is part of the hardware baseline.** Record vLLM build SHA, runtime/compiler, driver, host allocation, warmup and repeated runs before extrapolating device-level differences; Blackwell itself is not an Ascend comparison.
4. **Routing improvements need network physical evidence.** Packet simulator FCT is a hypothesis generator. A production-worthy P/D research claim needs NIC/collective tracing and real end-to-end TTFT/TPOT under pinned request loads.

**Reproduction state for all three admitted papers: `not_attempted`.** No code was compiled or evaluated on GPU/NPU by this intake. Next round should scan the *next actual arXiv November announcement*, deduplicate by arXiv ID, preserve holds until evidence changes and avoid creating a parallel database or adding organization announcements without clear implementation relevance.
