## Concrete next research checks

1. **Feather:** challenge 2–10× with same prefix distribution, cache capacity, Batch size, CPU profiler, and SLO goodput. Compare vLLM v0.23 cached vs uncached under repeated Prefix.
2. **ELDR:** expert signatures co-indexed with GPU KV blocks and routing choices could inform 4-NPU dynamic-serving experiments, but GPU/HCCL placement and weight layout differences require native baseline and A/A noise gate.
3. **BMV:** formally understand how midlayer pruning preserves exact target acceptance law; compare **target layer FLOPs saved vs branch bookkeeping + state memory**.
4. **IgniteServe:** cold-start benchmark instrumentation for model loading, graph compilation, capture; don't conflate TTR/launch readiness with steady-state throughput.
5. **Atrex/KREX:** adopt production-shape weighting and timing validity gates in agentic operator experiments; never infer NPU measurement stability from CUDA process-exclusive timing without verifying CANN runtime semantics.
