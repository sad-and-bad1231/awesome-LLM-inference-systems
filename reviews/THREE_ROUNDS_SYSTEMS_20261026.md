## Provenance corrections and editorial controls

- **One work / two names:** The SOSP'26 **official conference program** calls the work *Ave: Guiding Agentic GPU Optimization Using Data-Flow Invariants*; authors publish the closely matching [ARGUS version](https://mast.stanford.edu/pubs/argus_agentic_gpu_optimization_guided_by_data_flow_invariants/). **Same research identity by author list and mechanism**, not two papers. The existing Kernels canonical title should reflect the venue-title/author-title alias; row count does not change. (Official [SOSP program](https://sigops.org/s/conferences/sosp/2026/accepted.html).)
- Performance is explicitly *authors' reports*. No NPU/GPU hardware was accessible in this chat, no manuscript numerical results independently recomputed.
- Scope tiers: **physical real-serving** (DualPath in-house), **physical non-serving GPU kernels** (Meld/MorphX/Theseus), **different accelerator** (MeshRT), **private production experience** (Bedrock), **trace replay** (Vesta / Gandalf), **system simulation validated by physical replay** (compositional), and **model-changing approximation** (RaReCache) must never be collapsed into one leaderboard.
- Links prefer publisher paper-specific DOI, then author paper+artifact, then arXiv preprint. Each new row has one primary home, existing 44 directions unchanged; no automated legacy JSONL rewrite.

## Follow-up reproduction priorities

1. **Highest novelty for vLLM/Ascend direction:** MeldKernel (cross-SM fusion versus CANN synchronization semantics), DualPath (KV I/O scheduling and NIC saturation), RadixFlow (hybrid-state readiness in current scheduler), Vesta (cache affinity vs queue externality).
2. **Conditional but practical:** Gandalf (SSD write amplification before adding a storage tier), gKSM (CUDA VMM/fault assumptions before NPU translation), RaReCache (quality constraints before any lossless optimization comparisons).
3. **Do not attempt blind porting:** MorphX GPU kernel control, MeshRT wafer-scale scheduler, Theseus NCCL-specific CCL controls all require architecture-level feasibility analysis.
