# DeepSeek AI 系统工业专题设计

## 目标

把 `deepseek-topic.md` 中的 DeepSeek AI 系统论文、工具与项目纳入结构化工业事实层，并在两份工业视图中生成独立专题：

- `industrial-llm-inference-systems.md`
- `industry/README.md`

专题是聚合导航，不替代现有七主题主表，不复制 release notes 或长摘要。

## 方案选择

采用显式展示标签：相关工业记录在 `presentation.topic` 中标记 `deepseek-ai-systems`，渲染器据此聚合。相比按 `orgs` 或标题模糊匹配，该方案不会误收仅讨论 DeepSeek 的第三方项目，也能稳定覆盖架构论文、官方仓库和生态集合。

未采用的方案：

- 手工编辑两份 Markdown：会在下次渲染时丢失。
- 新建独立顶层清单：增加入口数量，与当前瘦身目标冲突。

## 内容与排序

专题按以下固定顺序展示：

1. 架构与系统
2. 核心算子与通信
3. 存储与数据路径
4. 推测解码
5. OCR 与生态

每项只展示名称、类别、系统作用和官方/正式材料链接。原有 DeepSeek 记录补上专题标签；缺失项目以独立工业事实记录加入。仅做少量官方来源核对，不采集星标等易漂移指标。

## 数据与渲染

- JSONL 仍是唯一事实源。
- 专题选择、分类和排序由共享函数完成，两份工业视图共用。
- 普通七主题主表和项目级聚合行为保持不变。
- `deepseek-topic.md` 作为用户输入保留，不作为运行时依赖，也不自动覆盖。

## 验收

- 两份工业视图都出现一个 DeepSeek 专题。
- 专题包含输入清单中的有效官方项目，且无重复项目。
- 第三方 DeepSeek 相关研究不会因名称命中进入专题。
- 重复执行 `render`、`publish` 无漂移。
- 全部单元测试和 `validate` 通过。
